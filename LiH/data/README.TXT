DEPOSIT INFORMATION

Description:    APPENDIX I and Appendix 2

PURE ROTATIONAL, VIBRATION-ROTATIONAL AND A - X  LINE POSITIONS 
(cm-1) FOR THE X1SIGMA+ AND A1SIGMA+ STATES OF LiH.

The accompanying ASCII file lists the line positions that were 
employed in the least squares fits described in the article. 
Lines considered to be unreliable were excluded and flagged as *U.

     For data sets where all measurments have the same accuracy, 
this is indicated in the header. When specific accuracies are 
assigned to individual measurements in a data set, this is indicated 
in the header with the phrase "variable precision".

                APPENDIX II

CALCULATED VIBRATIONAL TERMS AND ROTATIONAL PARAMETERS FOR 
FOUR ISOTOPOMERS OF LiH (X1SIGMA+), 6,7LiH AND 6,7LiD.

The file lists the parameters can that be used to calculate
reliable line positions for transitions within the ground state 
of individual isotopomers of CO(X). Sufficient significant figures
are provided in accord with the accuracies and (v,J) ranges of the
data sets employed to generate the parameters. 
The list for 12C16O is the same as table 5 in the article. 
Levels not observed experimentally are flagged with an asterisk.
